# Manchester City — Sky Blues Fan Page

Projeto front-end em HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Para uma experiência melhor, use o Live Server do VS Code.

## Recursos
- Layout responsivo
- Paleta Sky Blue / navy
- Animações de entrada por IntersectionObserver
- Contadores animados
- Cards de conquistas
- Abas interativas para Haaland, De Bruyne e Cherki
- Vídeo no final
- Menu mobile

## Observação sobre imagens
As fotos dos cards são carregadas por URLs externas públicas. Se uma fonte alterar o arquivo, o card continua com o degradê de fundo.

## Dados usados
- Manchester City 2022/23: 61 jogos, 44 vitórias, 151 gols, 27 clean sheets, sequência de 25 jogos invicto.
- Haaland 2022/23: 53 jogos, 52 gols, 9 assistências; 36 gols na Premier League.
- De Bruyne 2022/23: 28 assistências em todas as competições e 16 na Premier League. (*Jogos/gols no card são apresentados como referência visual; para um projeto publicado, recomendo alimentar todos os campos por uma única base estatística.)
- Cherki 2025/26: 52 aparições, 10 gols e 16 assistências segundo review do clube.

Projeto não oficial para fins educacionais/portfólio.
